# ইসলামি আর্থিক নীতি ও ত্রি-মাত্রিক হিসাব ব্যবস্থা

## রুল ২১: Head ≠ Fund ≠ Account

তিজারাহ সমিতি সফটওয়্যার ঐতিহ্যগত গতানুগতিক হিসাব ব্যবস্থার চেয়ে ভিন্ন ও ইসলামি শরীয়াহসম্মত ত্রি-মাত্রিক অ্যাকাউন্টিং আর্কিটেকচার মেনে চলে।

### ৩টি স্বতন্ত্র মাত্রা:

| মাত্রা | সংজ্ঞা | উদাহরণ |
| :--- | :--- | :--- |
| **১. খাত (Head)** | টাকা কেন এসেছে বা কেন খরচ হয়েছে (উদ্দেশ্য/কারণ) | সদস্য ফি, অনুদান, অফিস ভাড়া, স্টেশনারি |
| **২. তহবিল (Fund)** | টাকা কোন নীতি বা ফান্ডের অন্তর্ভুক্ত (দায়বদ্ধতা) | সাধারণ তহবিল, প্রশাসনিক তহবিল, শেয়ার তহবিল, প্রকল্প তহবিল |
| **৩. হিসাব (Account)**| টাকা বাস্তবিকভাবে কোথায় সংরক্ষিত (মাধ্যম) | ক্যাশ ইন হ্যান্ড, ইসলামী ব্যাংক চলতি হিসাব, বিকাশ |

### উদাহরণ চিত্র:
একটি সমিতি যখন সদস্যের কাছ থেকে ১,০০০ টাকা মাসিক সঞ্চয় গ্রহণ করে:
* **Head:** মাসিক নিয়মিত সঞ্চয় (আয়/দায় খাত)
* **Fund:** সাধারণ সঞ্চয় তহবিল (নির্দিষ্ট ফান্ড)
* **Account:** ক্যাশ ইন হ্যান্ড অথবা ব্যাংক একাউন্ট (যেখানে টাকা রক্ষিত)

এই তিনটি জিনিস কখনোই একে অপরের সাথে প্রতিস্থাপিত হবে না।
